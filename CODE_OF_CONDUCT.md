# Community expectations

Be respectful, specific and constructive. Assume contributors have different backgrounds and experience. Discuss the code and its behavior rather than making personal attacks.

Harassment, discrimination, threats, publishing someone else's private information and unwanted sexual attention are not welcome. Do not post credentials or identifying account screenshots, even when reporting a bug.

These expectations apply to issues, pull requests, discussions and other project spaces. Maintainers may edit or remove content, close a thread or restrict participation when needed to protect contributors.

To request a private reporting channel, open an issue asking to contact a maintainer without posting the sensitive details. Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md).
