Read it at a glance

A quota bar.
A pacing signal.

The bar shows how much you have used. The marker shows how much time has passed. The signed number is the difference between them, in percentage points.

Green: you have room

You are behind, on pace, or within 3 points of the paced allowance.

Yellow: ease off a little

You are more than 3 and up to 15 points ahead of the allowance.

Red: you are moving too fast

You are more than 15 points ahead, or the limit is already reached.

A few useful details

How does it connect to my accounts?

Codex login and token renewal use the official Codex CLI in separate app-owned profiles. Claude reads your existing Claude Code OAuth login, with explicit Keychain access when needed. The app does not make model requests. Read the setup guide.

What stays on my Mac?

Account labels, emails and usage snapshots remain in local app storage. Codex credentials are plaintext files in user-restricted directories. Claude credentials stay in its native store. There is no Usage Pace analytics service. This static website is hosted by GitHub Pages. Read the privacy details.

What if a provider only reports one limit?

The app shows the windows the provider supplies. A missing, stale or invalid window appears gray and shows ?%. It never guesses a quota or silently changes your selection.

Are downloads notarized?

No. Release apps are ad-hoc signed, not Apple Developer ID signed or notarized. macOS may decline to open a downloaded app. You can review and build the source with Xcode Command Line Tools.

Can I contribute?

Yes. Small, focused improvements are welcome. Start with the contribution guide. Report security concerns through private vulnerability reporting.
