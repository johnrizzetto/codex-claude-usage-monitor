# Changelog

## 1.0.0

- Native macOS menu bar app for two Codex profiles and one Claude account.
- Saved account and 5-hour/weekly window selection.
- Quota bar, elapsed-time marker and signed difference from perfect pacing.
- Green, yellow and red pacing signals, with gray unavailable states.
- Per-account usage, reset countdown, remaining allowance per hour and estimated exhaustion time.
- Five-minute refresh, manual refresh, pause and launch at login.
- Separate Codex OAuth homes and explicit Claude Code credential connection.
- Automated macOS build checks and a static GitHub Pages demo.
