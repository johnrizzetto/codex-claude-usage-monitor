# Changelog

## 1.0.2

- Return and Escape end badge editing, and clicking unused popover space releases the cursor.
- Opening the popover no longer automatically focuses a text field.
- Badges now accept emoji and symbols, preserving joined emoji, flags and skin tones within a four-character limit.
- Added a button to open the native emoji and symbol picker for a badge.

## 1.0.1

- Added an editable account badge to identify the selected menu bar account. Use CP, CW, PER or up to four letters or numbers.
- Saved custom badges across restarts, while retaining defaults for existing account data.
- Kept the badge neutral so pacing colors remain easy to read.

## 1.0.0

- Native macOS menu bar app for two Codex profiles and one Claude account.
- Saved account and 5-hour/weekly window selection.
- Quota bar, elapsed-time marker and signed difference from perfect pacing.
- Green, yellow and red pacing signals, with gray unavailable states.
- Per-account usage, reset countdown, remaining allowance per hour and estimated exhaustion time.
- Five-minute refresh, manual refresh, pause and launch at login.
- Separate Codex OAuth homes and explicit Claude Code credential connection.
- Automated macOS build checks and a static GitHub Pages demo.
